Guide sources

Each source becomes one guide at its own address on this server, for one Jellyfin guide provider limited to the tuners it's for. Jellyfin never contacts the sources itself: an XMLTV source is fetched at most every few minutes (General, below), Schedules Direct once a day.

Schedules Direct account

Shared by every Schedules Direct source. The plugin downloads only what changed, once a day (Scheduled Tasks → "Update Schedules Direct guide", 5:00), and only for the lineups the sources use, so Jellyfin's guide refreshes never reach Schedules Direct. Pictures are fetched the first time they're shown, then kept. Remove Jellyfin's own Schedules Direct guide provider once you use this, or it keeps asking them on every refresh.

General

The guide addresses need no sign-in (Jellyfin downloads them without one). On: only this server and the networks Jellyfin counts as local (Dashboard → Networking) can read them.
