Upstream guide

The URL Jellyfin's XMLTV guide provider used before, e.g. http://<channels-dvr>:8089/devices/<source>/guide/xmltv?duration=1209600
Each is cleaned the same way and served at its own address (below), so each Jellyfin guide provider can be limited to its own tuner, e.g. a Channels DVR HDHomeRun's /devices/<id>/guide/xmltv?duration=1209600.
Requests newer than this reuse the last cleaned copy.
If the upstream fails or times out, the last good cleaned copy is served instead.
The guide address needs no sign-in (Jellyfin downloads it without one). On: only the server itself and the networks Jellyfin counts as local (Dashboard → Networking) can read it.

Schedules Direct

A guide whose URL is sd:<lineup> (main or "More guides") comes from your Schedules Direct account. The plugin downloads what changed once a day (Scheduled Tasks → "Update Schedules Direct guide", 5:00) and keeps a copy here, so Jellyfin's guide refreshes never reach Schedules Direct. Pictures are fetched the first time they're shown, then kept. Remove Jellyfin's own Schedules Direct guide provider once you use this, or it keeps asking them on every refresh.
